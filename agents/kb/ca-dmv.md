# California DMV — Vehicle / Trailer Registration

A **truck** is a motor vehicle and a **trailer** is a registrable towed unit, so both must carry
current **California DMV registration**. This is the clearest line between vehicle-based and
sidewalk-based vendors:

- **truck** → DMV **vehicle** registration required.
- **trailer** → DMV **trailer** registration required (plus a registered tow vehicle).
- **pushcart_cooking** / **pushcart_nocook** → **NOT** a motor vehicle → **no DMV registration**.

This is why the pushcart checklists **exclude** any DMV step while the truck/trailer checklists
**include** one.

## What it covers (`cite: ca-dmv`)

1. Register the vehicle/trailer with the California DMV and keep registration current.
2. Provide proof of registration as a supporting document for the Public Works MFF application
   (within the **90-day document window**).
