# DPW Order No. 182,101 — Mobile Food Facility (MFF) Placement Rules

This is the **core law** that governs *where* a Mobile Food Facility may operate on the
public right-of-way in San Francisco. Person 3's clearance geometry check computes the real
distances against these rules and returns `cite: "dpw-182101"` for each row; the agents only
**explain** the result. Every distance figure below that is used by the geometry check is
frozen by `docs/CONTRACTS.md §B`.

> Honesty note surfaced to users: the in-app clearance checker is a **guide** based on these
> published distances, **not** an official clearance or legal determination. Final placement is
> subject to Public Works review.

## Clearance / distance rules (contract-pinned — authoritative)

| # | Rule | Required distance | Applies to | `cite` |
|---|---|---|---|---|
| 1 | Minimum distance from a **restaurant entrance** (fixed food establishment) | **75 ft** | all vendor types | `dpw-182101` |
| 2 | Minimum distance from a **fire hydrant** | **7 ft** | all vendor types | `dpw-182101` |
| 3 | Minimum distance from a **school** during **school hours** | **500 ft** | all vendor types | `dpw-182101` |

These three values are the ones the geometry Function evaluates (see `docs/CONTRACTS.md §B`
clearance example: `required_ft` 75 / 7 / 500). They must never be recomputed by the LLM — the
model reads `pass`/`actual_ft` from the Function and explains it.

## Other placement rules (structural — verify exact figures)

The Order also restricts placement in ways that are **structural and well established** but whose
exact numeric thresholds must be confirmed against the Order text before they are quoted with a
specific number. Stated here **without** invented figures:

- **Sidewalk pedestrian clearance:** an MFF must leave a minimum unobstructed **pedestrian path**
  on the sidewalk. This is the "wide sidewalk clearance" that matters most for **pushcarts**,
  which operate *on the sidewalk* (trucks/trailers operate from the *street/curb lane*). This rule
  has a **distinct legal basis** (SF Public Works Code + ADA path-of-travel), so it is cited to
  its own id **`sf-sidewalk-width`** (10 ft min = 6 ft path + 4 ft cart), **not** `dpw-182101`.
  See `sf-sidewalk-width.md`. `check_clearance` returns this as the 4th row for pushcart types.
- **Distance from another permitted MFF / claimed spot:** minimum spacing between mobile food
  facilities. Exact figure `SOURCE-NEEDED`.
- **Distance from intersections / crosswalks / driveways / bus zones / transit stops.** Exact
  figures `SOURCE-NEEDED`.
- **No placement blocking** building entrances, disabled-access ramps, or required egress.
- **Operating-hours and duration** limits at a given location.

## Citation labels

When Permit Copilot or Spot Scout cites a distance rule, use a human-readable `label` plus the
`source` id, e.g.:

```json
{ "label": "DPW Order 182,101 — 75 ft from restaurant entrance", "source": "dpw-182101",
  "quote": "A mobile food facility shall not be located within 75 feet of the entrance to a fixed food establishment." }
```

The `quote` above paraphrases the pinned rule; replace with the verbatim Order text once the
Order PDF is retrieved (`SOURCE-NEEDED`). The **number** (75 ft) is authoritative; the exact
wording is to be confirmed.
